# Publication Boundary

This repository is a code release, not a data release.

## Included

- source code and shell runbooks
- dependency manifests
- methodological documentation
- small, visibly synthetic fixtures when needed for tests

## Excluded

- original policy documents and licensed corpora
- candidate packages and model prompts containing source text
- document-level model responses
- panel datasets and research statistics
- logs, caches, checkpoints, and downloaded models
- SSH keys, API tokens, cookies, credentials, account identifiers, and private endpoints
- workstation or server-specific absolute paths

Use environment variables for all execution-specific values. Examples in documentation must use placeholders rather than details copied from a real machine or account.
